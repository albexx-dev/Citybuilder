# EPIC-67: Мини-карта — обзор города и телепорт камеры

Issue: #67 · Ярлык: ux · Зависимости: снимки зон/зданий (v1.1); события (v1.1) для маркеров

## Проблема

50×50 с камерой в упор: найти дом/станцию/пожар — скроллить камеру вручную. Мини-карта — стандарт жанра.

## Что увидит игрок

В углу экрана квадрат 140×140: зоны цветом, здания точками, дороги серым, маркеры событий (пожар — красный пульс, кража — оранжевый). Клик по миникарте — камера прыгает в то место.

## Архитектурный план

- `Scripts/UI/MinimapView.cs` (IMGUI): рисование в OnGUI по снимкам (клетки → пиксели в `Texture2D`, обновление раз в 0.5с — не каждый кадр) + маркеры поверх.
- Клик: `FreeCameraController` получает метод `FocusOn(GridPosition)` (добавить, тестируемый) — телепорт камеры.
- Позиция/размер: правый верхний угол, клампы `HudLayout` (новая секция MinimapRect), UiClickGuard rect.
- Перф: одна Texture2D 50×50, SetPixels раз в 0.5с — дёшево.

## Шаги

1. **minimap-view** — текстура + отрисовка снимков + тесты маппинга клетка→пиксель.
2. **markers-click** — маркеры событий + клик-телепорт (FocusOn + тест).
3. **layout** — секция HudLayout + гарды + низкие окна.

## План тестов

- Маппинг: клетка (0,0)/(49,49) → правильные пиксели текстуры.
- FocusOn: камера-цель ставится в мировые координаты клетки (чистая функция world-from-grid).
- Маркеры: активный пожар → маркер, потушен → маркер снят.

## Unity-приёмка (E2E)

Город с зонами/событиями: миникарта отображает реальность; клик — камера на месте; пожар пульсирует. Скриншот. Консоль чистая.

## Критерий закрытия эпика

Ориентация мгновенная, маркеры живые, перф не задет.

## Запрещено и риски

- RenderTexture живой камеры — НЕ использовать (дорого); только схематичная текстура.
- Риск: клик по миникарте проваливается в сетку — UiClickGuard rect обязателен.
