# EPIC-54: Модели для всех 10 типов зданий (Kenney)

Issue: #54 · Ярлык: content · ADR: **ADR-010 (до кода)** · Зависимости: пилот-конвейер уже в main (task/161, Shop = building-a)

## Проблема

Модель есть только у магазина. Остальные 9 типов — кубы-примитивы: город выглядит прототипом, хотя конвейер (импорт FBX → префаб с масштабом/пивотом → `BuildingDefinition.Prefab`) уже отработан и проверен в игре.

## Что увидит игрок

Каждый тип здания — узнаваемая low-poly модель: дома (Kenney Residential Kit), магазины/фабрики (Commercial/Industrial), электростанция/вода/мусор (Industrial), пожарная/полиция/больница/парк (City Kit + Hospital/Park уже есть из Blender). Варианты 2–3 на тип через `VariantCount`.

## Архитектурный план (фиксируется ADR-010)

- Источники: **Kenney CC0** базово (City Kit ×3, Industrial, Nature — все прямые ссылки через браузер, лицензия чистая); Sketchfab только CC0/CC-BY low-poly отдельными моделями.
- Конвейер (проверен): скачать → `Assets/Citybuilder/Models/<Vendor>/` → execute_code/мост: префаб (масштаб под Footprint, пивот в основании) → `BuildingDefinition.Prefab` (SerializedObject) → меты → коммит.
- Правила ADR-010: масштаб — модель вписывается в Footprint × высота по типу; полигонаж ≤3k на здание (Kenney — 200–1500, запас есть); пивот у земли; текстуры — атлас рядом с моделью; PNG → LFS (уже настроено).
- `CREDITS.md` — см. #55 (параллельный эпик).
- Варианты: `VariantCount` уже поддержан `SelectVariant` (v1.1 EPIC-17) — 2–3 модели на дом/магазин.
- Перф: 80 зданий × ≤1.5k tris — без просадок на built-in pipeline (проверить Static/Dynamic batching в билде).

## Шаги

1. **adr-assets** — ADR-010 (источники, масштаб, полигонаж, лицензии).
2. **models-residential** — дом ×3 варианта (Residential Kit) + hospital/park остаются.
3. **models-commercial** — магазин ×2 (уже есть building-a), фабрика (Industrial Kit).
4. **models-utility** — электростанция/вода/мусор (Industrial Kit).
5. **models-services** — пожарная/полиция (City Kit) + проверка hospital/park.
6. **perf-check** — билд-замер 80 зданий, профайлер.

## План тестов

- Домен не меняется: все тесты зелёные без правок (меняются только ассеты/префабы).
- Масштаб: каждая модель ровно Footprint по XZ (грид-проверка скриншотом).
- Валидатор: орфаны-меты, GUID-дубли — 0.

## Unity-приёмка (E2E)

Новый город → вырастить все 10 типов → ни одного куба; скриншоты каждого типа крупно; сейв/лоад не ломает виды. Билд smoke 80 зданий.

## Критерий закрытия эпика

Все 10 типов с моделями в одном стиле; валидатор и тесты зелёные; перф в лимите.

## Запрещено и риски

- Sketchfab-модели без CC0/CC-BY — запрещены (ADR-010).
- Риск стиля: не смешивать hi-poly и low-poly — один кит на тип.
- Риск LFS-квоты: текстуры только атласы, без лишних PNG.
