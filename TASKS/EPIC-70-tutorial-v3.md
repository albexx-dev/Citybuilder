# EPIC-70: Туториал v3 — шаги про новые механики

Issue: #70 · Ярлык: ux · Зависимости: поздние механики (#43/#44/#48/#51) · включает фикс текста из бага владельца («выбери станцию в палитре над панелью»)

## Проблема

Туториал v2 ведёт до больницы/парка. Новые механики (пожары, квесты, апгрейды, машины) игрок открывает вслепую. Плюс выясненный UX-провал: шаг «построй Электростанцию» не говорил, что станцию надо ВЫБРАТЬ В ПАЛИТРЕ — владелец потерялся.

## Что увидит игрок

Цепочка ~11 шагов: … → «Выбери Электростанцию в палитре НАД ПАНЕЛЬЮ и кликни клетку» (уточнённый текст!) → «Улучши станцию (инфопанель)» → «Выполни первую задачу (кнопка Задачи)» → «Убедись, что пожарная покрывает все дома» → «Понаблюдай за машинами утром». Тултипы (#66) подсвечивают нужные кнопки.

## Архитектурный план

- `TutorialPolicy`: +4–5 шагов с предикатами новых систем (апгрейд выполнен — флаг из `UpgradeController`, квест закрыт — из `QuestSystem`, станция выбрана в палитре — состояние палитры).
- Тексты шагов через реестр `UIText` (#66) — задел под #72.
- Подсветка кнопок нижней панели — уже есть (v1.1), расширить на кнопку «Задачи» и инфопанель.
- Пропуск «Понятно» сохраняется; после загрузки сейва туториал считается пройденным.

## Шаги

1. **steps-extend** — новые шаги + предикаты + тесты матрицы переходов.
2. **hint-texts** — уточнение текстов (включая шаг 4) через `UIText`.
3. **e2e-chain** — полный прогон цепочки как новичок.

## План тестов

- Матрица переходов: каждый шаг при своём предикате; пропуски недостижимых механик (система не готова) — шаг пропускается.
- Текст шага 4 содержит указание на палитру (регрессионный тест на текст!).

## Unity-приёмка (E2E)

Полный прогон новым игроком: до квестов и машин за ~15 минут; «Понятно» на середине глушит; сейв/лоад — туториала нет. Скриншот шага с палитрой.

## Критерий закрытия эпика

Все ключевые механики v1.2 объяснены; шаг-4-провал невозможен; тесты зелёные.

## Запрещено и риски

- Подсветка — только по `HudLayout` rect (падение отсутствующей кнопки — текст без рамки).
- Риск: шаги завязаны на эпики, которых ещё нет — предикаты с флагом готовности системы.
