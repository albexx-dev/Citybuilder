# EPIC-43: Пожары — возгорание, тушение, разрушение

Issue: #43 · Ярлык: mechanics · ADR: **ADR-009 (до кода)** · Зависимости: нет; события пишут в `CityEventLog` (v1.1)

## Проблема

Покрытие пожарных — процент в HUD. Ничего не горит, станция ничего не спасает, риск не ощущается. Перенос незавершённого эпика v1.1 #7 (был заморожен как кандидат v1.2).

## Что увидит игрок

Дом вне покрытия пожарных может загореться (редко): над зданием пламя-оверлей, событие «Пожар в доме!» в ленте. Станция в радиусе тушит за 1–2 тика. Без станции после N тиков дом разрушается: клетка освобождается, жители выселяются, событие «Дом сгорел дотла».

## Архитектурный план (фиксируется ADR-009)

- `Scripts/Simulation/FireSystem.cs` (plain C#): на тике перебор домов, для непокрытых — вероятность возгорания через детерминированный хеш `(tick, EntityId)` (никаких `System.Random` — тестируемость).
- Состояние: `Dictionary<EntityId, int> burning` (тикает горение); станция в радиусе (`ServiceBuildingSystem.Coverage01(Fire, ...)`) гасит за 1–2 тика; без станции после `BurnTicks = 6` — разрушение через логику `SettlementDemolitionController` (клетки, выселение `EvictHome`).
- События: `fire_started / fire_extinguished / house_burned_down` → `CityEventLog`.
- Визуал: `FireOverlayView` (Presentation) — материал пламени/пульс по снимку `FireSystem`, не в домене.
- Сейв: пожары НЕ сериализуются (короткоживущее состояние; после загрузки горящих нет — зафиксировать в ADR).
- Параметры: `IgniteChancePerTick` (≈0.002), `BurnTicks` (≈6) — калибруются в #53.

## Шаги

1. **adr-fire** — ADR-009 в `DECISIONS/` (один коммит-док).
2. **fire-domain** — `FireSystem` + тушение + разрушение + события + тесты на детерминизм.
3. **fire-view** — оверлей огня, связка через контроллер, тестовый хук форс-возгорания (для E2E).
4. **fire-balance** — калибровка p/N, интеграция с лентой и подсказками.

## План тестов

- Детерминизм: одинаковый `(tick, EntityId)` → одинаковое решение.
- Тушение: станция в радиусе → дом гаснет, здание живо.
- Разрушение: без станции → дом удалён, клетка освобождена, жители выселены, 3 события записаны.
- Покрытый дом не загорается вовсе; NaN в покрытии → treated as covered (безопасная сторона).

## Unity-приёмка (E2E)

Форс-возгорание хуком: огонь виден, событие в ленте; без станции дом сгорает и исчезает; поставить станцию → повторный поджог гасится. Сейв/лоад во время пожара: после загрузки горящих нет, город консистентен. Скриншот огня.

## Критерий закрытия эпика

Пожар редок, виден, станция решает; разрушение чистое; ADR-009 реализован как написано.

## Запрещено и риски

- Не запускать без ADR-009 и «го» владельца.
- Риск фрустрации: предупреждение в ленте заранее (пожарные 0% в городе с домами = событие-намёк).
