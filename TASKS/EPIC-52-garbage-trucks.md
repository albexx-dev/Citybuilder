# EPIC-52: Мусоровозы — вывоз мусора как видимая услуга

Issue: #52 · Ярлык: mechanics · Зависимости: **#44 (AgentManager)**; `WasteController` (v1.1)

## Проблема

Мусор — ёмкость полигона в HUD. Никто ничего не вывозит: услуга невидима, переполнение абстрактно.

## Что увидит игрок

Мусоровоз выезжает из полигона, объезжает дома с мусором (визуально переполненные — мусорные баки/кучки у дома), вывозит, возвращается. Дом без вывоза — visibly переполнен, комфорт падает.

## Архитектурный план

- Агент-мусоровоз на базе `AgentManager` (#44): маршрут полигон → дома с мусором → полигон; без полигона — нет агента.
- `WasteController` v2: у каждого дома счётчик `WasteAccumulated` (растёт с тика по `WasteOutput`); вывоз обнуляет у посещённых домов; полигонная ёмкость суммирует накопленное (существующая `WasteCapacity` — лимит свалки).
- Переполнение: дом с мусором > порога → −комфорт жилья (модификатор, паттерн #47) + событие в ленту «Дом переполнен мусором».
- Виды: мусоровоз — модель из #60; переполнение — декаль/бак-оверлей (Presentation).
- Сейв: счётчики домов в v5 (#64); агент не сериализуется.

## Шаги

1. **waste-accum** — счётчики по домам + пороги + тесты (рост/порог/обнуление).
2. **truck-agent** — агент-маршрут на базе #44 + вывоз + тесты.
3. **truck-view** — модель + переполнение-оверлей + события.

## План тестов

- Накопление: дом × Output/тик; порог пересечён → флаг переполнения + событие один раз.
- Вывоз: обнуление посещённых; полигон-ёмкость уменьшается/учитывается корректно.
- Без полигона: агент не спавнится, накопление продолжается.

## Unity-приёмка (E2E)

Город без полигона-вывоза: дома visibly переполнены, комфорт падает; построить WasteDepot → мусоровоз ездит, дома чистятся. Скриншот переполненного дома и мусоровоза. Консоль чистая.

## Критерий закрытия эпика

Вывоз видим и осмыслен; перф в лимите; баланс порогов подтверждён в #53.

## Запрещено и риски

- Не ломать существующий `SupplyBalance`-мусор (каналы разные: свалка = хранилище, вывоз = сервис) — зафиксировать в ADR-011 дополнением.
- Риск перфа: маршрут пересчёта раз в выезд, не каждый тик.
