# EPIC-51: Апгрейд служб — станции улучшаются

Issue: #51 · Ярлык: mechanics · Зависимости: инфопанель (v1.1); сейв v5 (#64) для уровня

## Проблема

Станции одноразовые: нужен больший радиус — ставь вторую. Апгрейд существующей — классическая городостроительная механика и осмысленный слив казны.

## Что увидит игрок

Клик по станции в инфопанели: кнопка «Улучшить — $N» (N растёт с уровнем). Улучшение: +радиус (или +мощность для утилити). Уровень виден в панели (звёзды/цифра), модель слегка меняется (надстройка — #61 точка интеграции).

## Архитектурный план

- `BuildingState`: поле `Level` (int, 1..3). `BuildingDefinition`: параметры апгрейда — `UpgradeCost1/2`, приросты (радиус +2, мощность +6) — простые константы по типу (не новый ScriptableObject).
- `UpgradeController` (Construction): проверка казны (`Treasury.Spend`), применение к state, пересчёт покрытия (ServiceBuildingSystem snapshot rebuild — уже есть), MarkDirty для автосейва (паттерн PR #41).
- Инфопанель (`InfoPanelView`): кнопка «Улучшить» для станций/служб, уровни 1..3.
- Сейв: уровень в снапшот v5 (#64); восстановление через `HouseholdBinder`-подобный апликатор.
- Ограничение: максимум 3 уровня; ручные и выросшие станции — одинаково (уровень по state).

## Шаги

1. **upgrade-domain** — Level в state, параметры в definition, `UpgradeController` + тесты (цена/казна/пересчёт покрытия).
2. **upgrade-ui** — кнопка в инфопанели + перерисовка строки покрытия.
3. **upgrade-save** — v5 поля (#64) + round-trip тесты.

## План тестов

- Апгрейд 1→2: радиус вырос, покрытие домов пересчиталось, деньги списаны; при нехватке — отказ (гад).
- Уровень 3 → кнопка скрыта (максимум).
- Сейв/лоад: уровень восстановлен, покрытие сходится.

## Unity-приёмка (E2E)

Поставить пожарную → улучшить дважды → радиус-оверлей вырос (инфопанель v1.1 показывает радиус), дома покрылись; снос/новая — уровень сброшен. Скриншот панели с кнопкой.

## Критерий закрытия эпика

Апгрейд работает, виден, сохраняется; баланс цены против новой станции осмыслен (подтвердить в #53).

## Запрещено и риски

- Не апгрейдить жилые дома (это #59 «уровни зданий» с другими правилами).
- Риск: забытый MarkDirty → автосейв не заметит улучшение — тест обязателен.
