# EPIC-12: Инфопанель здания

Issue: #12 · Ярлык: architecture · Зависимости: нет; строка статуса зданий обогащается после EPIC-02..05

## Проблема

«Почему так» недоступно: клик по дому не говорит, кто там живёт, что с его нуждами; клик по станции не показывает радиус и покрытие. Игрок видит только агрегаты в HUD.

## Что увидит игрок

Клик по зданию открывает панель у края экрана:
- **дом**: жители (семей/человек), нужды дома (покрытие энергией/водой/мусором/пожарными/больницей/парком — %), связность дорогой (да/нет);
- **станция/служба**: тип, радиус в клетках, сколько домов покрывает (N/M), обслуживание (содержание из EPIC-04);
- **стройка/дорога**: стоимость, состояние.
Закрытие — Esc, повторный клик или клик мимо. Радиус выбранной службы подсвечивается на сетке.

## Архитектурный план

- `BuildingInfoQuery.cs` (Core или Infrastructure, plain C#): по `GridPosition` возвращает снимок `BuildingInfo` (тип, definition id, жители, покрытия, радиус, содержание). Составляется из существующих систем через уже доступные запросы/снимки — новых связей между модулями не заводить: контрольные примеры — World не узнаёт про деньги, панель собирает данные на уровне контроллера-адаптера.
- `InfoPanelView.cs` (UI, IMGUI): окно фиксированного положения (правый нижний угол над нижней панелью EPIC-13), подложка `HudText`, закрытие по Esc/клику мимо; `UiClickGuard` регистрирует прямоугольник панели (клик по панели не проваливается в сетку — паттерн задачи 032).
- Подсветка радиуса: `GridVisualizer` — новый оверлей-слой (клетки в радиусе ServiceRadius полупрозрачным цветом вида службы); данные радиуса — из `BuildingInfo`.

Что НЕ делаем: редактирование здания из панели, история изменений, подсветка маршрутов/пробок (EPIC-15), rename-рефакторинги соседних систем.

## Шаги

1. **info-query** — `BuildingInfoQuery` + `BuildingInfo` + тесты (дом/станция/пустая клетка/вне карты).
2. **panel-view** — `InfoPanelView` + клик-хендлер + гарды; E2E для дома и станции.
3. **radius-overlay** — подсветка радиуса в `GridVisualizer`; тест порогов/границ радиуса (граница клетки входит).

## План тестов

- Query: дом с 1 семьёй на 4 человек → снимок совпадает; станция r6 → покрывает N из M домов (сверить с HUD-строкой — числа равны).
- Пустая клетка/вне карты → пустой info, панель не открывается, исключений нет.
- Подсветка: клетки радиуса 6 от центра (x,y) — ровно множество, которое даёт `ServiceCoverage` (единый источник правды, не дублировать математику).

## Unity-приёмка (E2E)

Клик по дому → панель с жителями и покрытием; клик по пожарной → радиус подсветился, N/M совпадает с HUD; Esc закрывает; клик по панели не ставит дорогу под ней. Скриншоты панели для дома и станции. Консоль чистая.

## Критерий закрытия эпика

Любое здание отвечает «кто я, что мне нужно, что я покрываю» в один клик; гарды кликов не дырявятся; тесты зелёные.

## Запрещено / риски

- Не тянуть данные напрямую из MonoBehaviours других систем — только через существующие снимки/запросы (иначе родим циклы, запрещённые ARCHITECTURE §10).
- Риск: панель съедает клики нижней панели при наложении — позиции согласовать с EPIC-13 (`HudLayout` — единый источник прямоугольников).
