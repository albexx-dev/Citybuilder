# EPIC-20: Blender-конвейер — адон + модели больницы и парка

Issue: #20 · Ярлык: content · Зависимости: EPIC-02 (определения зданий существуют); Blender MCP на 127.0.0.1:9876 подключён (задача 103)

## Проблема

Все здания — примитивы с крышей (задача 022). Blender MCP подключён и отвечает (`get_scene_info` — задача 103), но конвейера нет: каждая модель делается руками и импортируется с ручной подгонкой. `UNITY_MCP_SETUP.md` описывает мост, но не адон.

## Что увидит игрок

Больница и парк — не кубы: узнаваемые low-poly модели (корпус с крестом/деревья и дорожки). За кадром — повторяемый конвейер для будущих зданий.

## Архитектурный план

- **Адон** `Tools/blender-addon/citybuilder_export.py`: панель в Blender (N-панель «Citybuilder»):
  - кнопка Export FBX: применяет трансформы, экспорт в `Assets/Citybuilder/Models/<name>.fbx` с фиксированными настройками (scale 1.0, оси Unity: forward −Z... фактически Unity-импорт: Apply Transform on, Bake Animation off, Y up);
  - валидация перед экспортом: один меш-объект (или коллекция), реальный масштаб в метрах (клетка 1x1), pivot в основании здания;
  - установка адона описывается шагом в `UNITY_MCP_SETUP.md` (Edit → Preferences → Add-ons → Install).
- **Модели** (через Blender MCP, итеративно): `hospital` (~3x3x2.5 клеток), `park` (2x2x1: 2-3 дерева low-poly, дорожки, лавочка) — материалы простые (vertex color или 2-3 материала), полигонаж ≤ 2k на здание.
- **Импорт**: FBX в `Assets/Citybuilder/Models/`, префабы через `BuildingViewFactory` — definition `Hospital/Park` получают model-prefab вместо примитива; масштаб сверяется гридом (клетки).
- Стандарт репо: `.gitattributes` уже объявляет LFS для fbx (сейчас LFS не используется — при первом fbx решить: LFS включать или обычный git; файл маленький, допускаем обычный git и пометить в доке).

Что НЕ делаем: замена всех зданий (только больница+парк; дома/магазины — по желанию владельца отдельно), анимации, скелеты, текстурные атласы.

## Шаги

1. **addon-export** — адон + экспорт тестового куба → FBX попадает в Models с правильными настройками; UNITY_MCP_SETUP дополнен.
2. **model-hospital** — модель больницы через Blender MCP (скрин в Blender → экспорт → префаб → в игре).
3. **model-park** — парк аналогично.

## План тестов

- Конвейер: экспорт адоном повторяем (два экспорта подряд — идентичный файл по хешу).
- Масштаб: модель больницы занимает ровно 3x3 клетки грида (сверка в редакторе).
- Домен не затронут: все тесты зелёные без правок (меняется только префаб в ассете).

## Unity-приёмка (E2E)

Поставить больницу и парк в игре: модель стоит на своих 3x3/2x2, не парит и не тонет, читается издалека; снос/сейв-лоад работают. Скриншоты в игре крупным планом. Консоль чистая (без warning импорта).

## Критерий закрытия эпика

Адон экспортирует одной кнопкой, две модели в игре, UNITY_MCP_SETUP описывает адон, конвейер готов к следующим зданиям.

## Запрещено / риски

- Не тащить в адон зависимости от сторонних библиотек Blender — только bpy API.
- Риск: FBX-импорт Unity тянет лишние материалы/камеры — префаб чистится, лишнее удаляется до коммита (import-настройки фиксируются в доке).
- LFS-вопрос решить в шаге 1 осознанно (маленькие файлы — обычный git).
