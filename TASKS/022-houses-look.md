# TASKS/022 — Houses Look

## Цель

Выросшие дома читаются как отдельные дома вплотную: швы между соседями, разная высота, крыша. Только вид, логика не меняется.

## Контекст

По скриншоту: соседние 2×2-кубы сливаются в одну бежевую массу без швов и объёма. Модуль Presentation, правится только SettlementView.

## Что нужно сделать

1. `SettlementView` (изменить, модуль Presentation — ТОЛЬКО BuildCube/SpawnView окружение):
   - Куб ужатый: footprint × 0.9 по XZ (шов 0.1 клетки между соседями; логические клетки не меняются — только визуал).
   - Высота по Id: `1f + (state.Id.Value % 3) * 0.5f` (1 / 1.5 / 2 — разнообразие; детерминировано, без рандома).
   - Крыша: второй бокс ребёнком куба — верхняя плита (0.7 ширины/глубины, 0.3 высота, по центру верха), цвет тёмно-коричневый (0.45, 0.25, 0.1), Unlit/Color. Удаляется вместе с домом (ребёнок — один Destroy).
   - Стены — текущий бежевый FallbackColor. Префаб-путь (def.Prefab) не трогать.
   - Коллайдеры удалять у обоих боксов.

## Что не нужно делать

- Не трогать логику роста, вместимость, остальные файлы.
