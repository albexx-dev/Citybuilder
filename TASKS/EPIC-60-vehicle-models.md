# EPIC-60: Модели транспорта — машины, мусоровозы

Issue: #60 · Ярлык: content · Зависимости: **#44** (агенты), #52 (мусоровозы); конвейер из #54/ADR-010

## Проблема

Агенты #44/#52 стартуют с капсул/кубов — транспорт без моделей выглядит заглушкой на фоне модных зданий (#54).

## Что увидит игрок

По дорогам едут узнаваемые low-poly машинки (2–3 варианта цветов/типов легковушек), мусоровоз — прямоугольная будка с баком. Вариант машины детерминирован по агенту.

## Архитектурный план

- Источник: Kenney Vehicle Kit / Car Kit (CC0, конвейер ADR-010) — 2–3 легковушки + 1 мусоровоз; полигонаж ≤800 на машину.
- `VehicleAgentView`: пул видов (см. #62), выбор варианта по `seed = EntityId % variants`; ориентация по направлению движения.
- Мусоровоз — отдельный вид для агента #52 (бытовые машины не возят мусор).
- Материалы: атлас из кита, без PBR-тяжёлых наборов (built-in pipeline).

## Шаги

1. **vehicle-import** — импорт моделей + префабы + CREDITS (#55) + меты.
2. **variant-view** — пул видов с вариантами + ориентация + тесты детерминизма выбора.
3. **garbage-view** — вид мусоровоза для #52.

## План тестов

- Вариант по seed детерминирован; пул переиспользует виды без утечек.
- Ориентация: направление движения → поворот (тесты на 4 направления клеток).

## Unity-приёмка (E2E)

Поток машин (#44) с разными машинками; мусоровоз ездит по маршруту (#52). Скриншот дороги с транспортом. Перф в лимите (#62).

## Критерий закрытия эпика

Транспорт с моделями в едином стиле, перф в лимите, CREDITS заполнен.

## Запрещено и риски

- Rigidbody/физика — запрещено (позиции из агентов, движение по клеткам).
- Риск: слишком яркие материалы — привести к палитре города.
