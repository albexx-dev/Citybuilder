# TASKS/097-breakdown — понятность старта (пункт 1 чек-листа 093)

Дата: 26.10.2026. Ветка: task/097-start-clarity. Модуль: UI.

## Ввод
При запуске игрок видит HUD из нулей и кнопки режимов, но не знает первого действия. Рост домов включается только режимом «Рост [4]», а зоны рисуются только в режиме «Зоны [3]» — без подсказки связку не угадать.

## Действие игрока
Запустить игру и прочитать на экране: «[3] → Жилая → закрась 4×4»; закрасить участок → подсказка меняется на «[4] Рост»; включить рост → «первый дом через N ч»; вырос первый дом → подсказка исчезает.

## Шаги
- [x] `StartHintPolicy` — чистая логика: PaintZones / EnableGrowth / WaitForHouse / Done по числу жилых клеток, выросших домов и режиму.
- [x] `StartHintView` — строка HUD на y=430, ссылки ленивые с того же объекта.
- [x] Тесты `StartHintPolicyTests` — 5 случаев, включая режим «Рост» без зон.
- [x] Сцена: компонент на Grid.
- [x] Play-E2E: старт → скриншот, закраска зоны, переключение режима, подсказка исчезает после первого дома.

## Лимиты
Файлы ≤150 строк, методы ≤30, 1 файл = 1 класс, `HudText` не менять.

## Приёмка
EditMode зелёные; Play-E2E со скриншотом; Console без ошибок.
