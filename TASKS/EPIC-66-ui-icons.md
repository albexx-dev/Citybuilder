# EPIC-66: Иконки UI + тултипы на кнопки

Issue: #66 · Ярлык: ux · Зависимости: #54 (единый стиль); Kenney UI Pack (CC0, конвейер ADR-010)

## Проблема

Все кнопки — текст (Домa [1], x4, Статистика): мелким шрифтом IMGUI-кнопки читаются плохо, показатели инфоменю непонятны без документации.

## Что увидит игрок

Кнопки с иконками (дом/дорога/кисточка/рост/пауза-плей-ускорение/газета/шестерёнка) + при наведении — тултип с описанием. Показатели инфоменю тоже с тултипами («Занятость 44% — доля работающих среди способных»).

## Архитектурный план

- Kenney UI Pack (CC0): иконки 32px в `Assets/Citybuilder/UI/Icons/`, конвейер ADR-010, CREDITS (#55).
- `BottomBarStyle.DrawIconButton(Rect, Texture, label, highlighted)` — иконка + подпись на кнопке (GUI.Label поверх).
- `TooltipView` (UI, IMGUI): статический `TooltipDrawer.Draw(rect, text)` — задержка 0.4с по hover, строка с подложкой `HudText`; реестр текстов `UIText.cs` (plain C# словарь ключ→строка — задел под #72).
- Тултипы: кнопки нижней панели, показатели инфоменю, кнопки палитры (цена + требование).

## Шаги

1. **icons-import** — UI-пак, `DrawIconButton`, замена на всех кнопках панели.
2. **tooltip-core** — `TooltipView` + `UIText` реестр + тесты (чистая логика тайминга).
3. **tooltips-content** — тултипы на все показатели инфоменю (тексты по GAME_DESIGN).

## План тестов

- Тайминг тултипа: hover 0.4с → показан; ушёл курсор → скрыт (чистая функция от времени).
- Реестр: ключ без строки → fallback на ключ (не краш).

## Unity-приёмка (E2E)

Скриншот панели с иконками; тултипы на каждом показателе; 1024px окно — ничего не наезжает. Консоль чистая.

## Критерий закрытия эпика

UI читается иконками, всё объясняется наведением, стиль единый.

## Запрещено и риски

- Только CC0-иконки с записью в CREDITS (#55).
- Риск: иконки разного стиля из разных паков — только один UI Pack.
