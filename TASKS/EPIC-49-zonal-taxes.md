# EPIC-49: Налоги по типам зон — раздельные ставки

Issue: #49 · Ярлык: mechanics · Зависимости: сейв v5 (#64) для хранения; инфоменю (v1.1)

## Проблема

Одна налоговая ставка на всё: игрок не может выбирать «низкие налоги жителям, высокие магазинам» — глубины экономической политики нет.

## Что увидит игрок

В инфоменю секция «Бюджет»: три строки налогов — Жилая / Коммерция / Промзона, у каждой свой уровень 1/2/3 и фактический сбор «+N $/ч». Кнопка «Новая» сбрасывает все три.

## Архитектурный план

- `TaxPolicy` v2 (plain C#): вместо одной ставки — `int[] rates` по `ZoneType` (Residential/Commercial/Industrial); API `RateFor(ZoneType)` обратно совместим: старый `Level` = все три равны (v4-совместимость).
- `TaxSystem.Collect`: разнос дохода по зонам-источникам (дом → Residential, магазин → Commercial, фабрика → Industrial; известные типы из `BuildingDefinition.AllowedZone`).
- UI: 3 строки-кнопки в `InfoMenuView` (секция «Бюджет») по образцу существующей `TaxPolicyView`.
- Сейв: снапшот v5 — 3 поля ставок; чтение v4 → все три = старой ставке.
- Экономика: жилая ставка влияет на удовлетворённость (высокая → −досуг), коммерция/пром — только деньги (просто и понятно для v1.2).

## Шаги

1. **policy-split** — `TaxPolicy` v2 + `TaxSystem` разнос + тесты.
2. **save-v5-partial** — поля ставок в снапшот (координация с #64, если тот ещё не сделан — минимальная версия полей).
3. **budget-ui** — 3 строки в инфоменю + E2E.

## План тестов

- Разнос по зонам: дом/магазин/фабрика → свои ставки.
- v4-сейв → читается с равными ставками; v5 round-trip.
- «Новая» сбрасывает все три; Employment-гейт не задет.

## Unity-приёмка (E2E)

Выставить Коммерцию=3, Жилая=1: сбор с магазинов ×3, жители довольны; «Новая» → все «обычный». Скриншот секции бюджета.

## Критерий закрытия эпика

Три раздельные ставки работают, сохраняются, читаются из старых сейвов; тесты зелёные.

## Запрещено и риски

- Не трогать `TaxPolicy.Income` контракт (задача 100) — расширение, не замена.
- Риск балансный: коммерция ×3 может убить магазины — цифры подтвердить в #53.
