# TASKS/101-breakdown — деньги не теряются при росте (долг из HANDOFF §6)

Дата: 26.10.2026. Ветка: task/101-growth-payment. Модуль: Population (контроллер роста).

## Ввод
`SettlementGrowthController.TryGrow` списывал плату до `Settle`. Если `Settle` возвращал `null`, деньги уже ушли — тихая потеря. Обратный порядок исключает потерю: сначала проверка `CanAfford`, затем постройка, затем списание; неудачное списание откатывает дом.

## Действие игрока
Ничего не меняется в нормальном росте: дом стоит ровно столько же и списывается один раз. При нехватке денег дом не строится и казна не меняется.

- [x] Play-E2E: ровно одно списание за дом; казна на 1 меньше цены → дом не растёт, казна не меняется.
