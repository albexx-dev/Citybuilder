# TASKS/065-breakdown

Задача: оркестратор 065, модуль Population + UI (2 файла кода + 1 тест + сцена). По образцу 061 (энергия в нуждах): вода становится опциональным провайдером `NeedSystem`, добавляет 5-й показатель в HUD и участвует в среднем только при подключении. Въезд и рост от воды по-прежнему не зависят. Исполнитель: Engineer (субагент). Приёмка и сцена — оркестратор.

Контекст: `NeedSystem` (134 строки) сейчас считает среднее по 3 базовым потребностям и опционально по энергии (4-частное). `NeedsView` на объекте Population в сцене передаёт провайдер энергии. `WaterController` уже висит на Grid и отдаёт `Rate01` (0..1). Старые тесты `NeedSystemTests` и `PowerNeedTests` обязаны остаться зелёными без правок.

Запрещено: менять `WaterSystem`, `WaterController`, `PowerController`, `PopulationController`, `SettlementGrowthController`, сцену (сцену вяжет оркестратор), правила роста/въезда, ProjectSettings. Новых пакетов нет. Ручного копирования кода нет.
