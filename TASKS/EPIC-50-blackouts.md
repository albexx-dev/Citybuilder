# EPIC-50: Блэкауты — перегрузка сети видимо отключает здания

Issue: #50 · Ярлык: mechanics · Зависимости: `SupplyBalance`/`PowerController` (v1.1); синергия с #58 (тёмные окна ночью)

## Проблема

Дефицит энергии — только множитель роста (GrowthPace). Здания внешне не отличить: игрок не видит, ЧТО именно отключено и чей комфорт упал.

## Что увидит игрок

При дефиците энергии часть зданий видимо отключается: тёмные окна (днём — приглушённый вид, ночью — не светятся, см. #58), отключённый дом — нулевой комфорт жилья. Приоритет отключения — детерминированный (по EntityId), живёт до восстановления баланса. Событие в ленту: «Отключены N зданий (дефицит энергии)».

## Архитектурный план

- `SupplyBalance` v2 (Core, обратно совместимо): при demand > supply — распределение отключений: `bool IsPowered(EntityId)` — детерминированно по хешу id, столько зданий, сколько не хватает.
- `PowerController` публикует снимок отключённых; `BuildingViewFactory`/`FireOverlayView`-стиль — материал «обесточено» (приглушение) на видах.
- `NeedProviders`/`NeedSystem`: отключённый дом даёт 0 по энергии (сейчас — пропорциональный brownout из задачи 059 — заменяется точечным списком, старые перегрузки конструкторов сохраняются).
- Событие в ленту при изменении числа отключённых.
- Сейв: не сериализуется (восстанавливается пересчётом — детерминировано).

## Шаги

1. **cutoff-domain** — распределение в `SupplyBalance` + `IsPowered` + тесты (детерминизм, границы, NaN).
2. **cutoff-view** — материал обесточивания на видах + событие в ленту.
3. **needs-link** — интеграция с `NeedSystem` (отключённый = 0 энергии) + E2E.

## План тестов

- Дефицит 2 из 10 → ровно 2 отключённых, набор детерминирован (хеш-порядок стабилен между запусками).
- Восстановление (снос потребителя) → все включены.
- NaN/0 потребителей → без исключений.

## Unity-приёмка (E2E)

16 домов без станции → часть тёмная (видно), нужды просели; построить станцию → светлеют за тик; лента зафиксировала. Скриншот тёмных зданий. Консоль чистая.

## Критерий закрытия эпика

Дефицит виден глазами и точечен; детерминирован; старые тесты brownout обновлены честно.

## Запрещено и риски

- Не трогать воду/мусор в этом эпике (только электричество — самый видимый).
- Риск: перерисовка материала каждый тик — кешировать, менять только при изменении набора отключённых.
