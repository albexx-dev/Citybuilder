# EPIC-48: Квесты-вехи — бесконечные цепочки задач с наградами

Issue: #48 · Ярлык: mechanics · ADR: **ADR-012 (до кода)** · Зависимости: поздние механики для полного набора квестов (#43/#44/#47)

## Проблема

Цель со ступенями 50/100/200 — одна линейка, после 200 игрок без ориентиров. «Игра» ведёт игрока задачами, но доктрина запрещает финал — значит нужны бесконечно генерируемые вехи с наградами.

## Что увидит игрок

Кнопка «Задачи» в нижней панели: 1–3 активных задачи («Построй больницу», «Достигни 100 жителей», «Потуши пожар»), прогресс-полоски, награда из казны по выполнении, на замену приходит новая задача из генератора. Финала нет — цепочки продолжаются.

## Архитектурный план (фиксируется ADR-012)

- `Scripts/Population/QuestSystem.cs` (plain C#): квест = `{id, title, description, проверка (предикат по снимку города), награда}`; состояние: активные 3 + выполненные (id-список для неповтора).
- `QuestCatalog.cs` — статический каталог условий по системам ( grown-счётчик, службы, казна, пожары потушены, кражи 0 за день, население). Генератор: берёт подходящие по прогрессу города, исключая выполненные.
- `QuestLogView` (UI, IMGUI): панель задач с прогрессом, кнопка в нижней панели + хоткей Q.
- Награда: `Treasury.Spend`-обратная операция (пополнение с событием в ленту «Задача выполнена: +$500»).
- Сейв: активные + выполненные id в снапшот v5 (#64).

## Шаги

1. **adr-quests** — ADR-012 (формат, генерация, состояние).
2. **quest-domain** — `QuestSystem` + каталог 10 квестов + генератор + тесты (переходы, неповторы, границы).
3. **quest-ui** — `QuestLogView` + кнопка/хоткей + уведомление в ленту.
4. **quest-save** — сериализация в v5 (#64) + тесты round-trip.

## План тестов

- Переходы: условие сработало ровно раз; награда списана; на замену пришёл не-выполненный квест.
- Генератор: при 0 зданий не выдаёт «построй больницу» (недоступную) — сортировка по доступности.
- Сейв: выполненные не повторяются после загрузки.

## Unity-приёмка (E2E)

Новая игра: 3 стартовых задачи; выполнить одну → награда, новая задача; Q открывает/закрывает; сейв/лоад сохраняет прогресс. Скриншот панели задач.

## Критерий закрытия эпика

Игрок всегда имеет 1–3 осмысленные задачи; награды работают; бесконечность без повторов; тесты зелёные.

## Запрещено и риски

- Не ломать доктрину: квесты не создают «конца игры», только вехи.
- Риск: квесты недостижимы при заблокированных системах (пожары до #43) — каталог сортируется по готовности (флаг «система реализована»).
