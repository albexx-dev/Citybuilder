# EPIC-07: Пожары как событие (кандидат v1.2)

Issue: #7 · Ярлык: mechanics · Статус: **on hold** — стартует только по решению владельца (v1.1 или v1.2) · Перед кодом обязателен малый ADR-009

## Проблема

Покрытие пожарных — только проценты в HUD: ничего не горит, станция не спасает, риск не ощущается. Драма и смысл покрытия отсутствуют.

## Что увидит игрок

Дом без покрытия пожарных может загореться (редко): над зданием огонь, событие в ленте; если в радиусе есть станция — пожарные тушат за пару тиков; если нет — дом сгорает (исчезает, жители выселяются, клетка освобождается, событие «дом сгорел»).

## Архитектурный план (черновик под ADR-009)

- `FireSystem.cs` (Simulation, plain C#): на тике для каждого незакрытого пожарными дома вероятность возгорания p (малая, например 0.002/тик); псевдослучайность — детерминированный хеш (tick, EntityId), никаких System.Random в домене.
- Состояние пожара: `BurningState` в системе (EntityId → тики горит); станция в радиусе — тушение за 1-2 тика; без станции после N тиков (например 6) — дом разрушается через существующий демонтаж-путь (`SettlementDemolitionController`-логика), жители выселяются `EvictHome`.
- События: `fire_started`, `fire_extinguished`, `house_burned_down` → лента (EPIC-09).
- Визуал: `BuildingViewFactory` — оверлей огня (материал/цвет-пульс), гашение по событию; не в домене.
- Сейв: пожары НЕ сериализуются (короткоживущее состояние; после загрузки горящих нет — приемлемо, зафиксировать в ADR).
- Баланс: p и N калибруются так, чтобы за 30 минут без станций сгорало 0-2 дома, с покрытием — 0.

## Шаги (после ADR-009)

1. **fire-domain** — `FireSystem` + тушение/разрушение + события; тесты на детерминированные хеши.
2. **fire-view** — оверлей огня, связь через контроллер; E2E поджог (тестовый хук для форс-мажора в редакторе).
3. **fire-balance** — калибровка p/N по прогонам; согласование с EPIC-06.

## План тестов

- Детерминизм: одинаковый (tick, EntityId) → одинаковое решение гореть/не гореть.
- Тушение: станция в радиусе → дом гаснет через N тиков, здание живо.
- Разрушение: без станции → дом удалён, клетка освобождена, жители выселены, события записаны.
- Покрытый дом не загорается вовсе.

## Unity-приёмка (E2E)

Форс-возгорание через тестовый хук: увидеть огонь, событие; без станции дом сгорает и исчезает; поставить станцию рядом → повторный поджог гасится. Сейв/лоад во время пожара — горящих после загрузки нет, город консистентен. Скриншот огня.

## Критерий закрытия эпика

Пожар редок, видим, станция решает; разрушение чистое (клетки, жители, события); баланс не разрушает игру; ADR-009 реализован как написано.

## Запрещено / риски

- Не запускать без явного «го» владельца и ADR-009 — эпик может остаться в v1.2.
- Риск фрустрации: разрушение прогресса злит. Противоядие в балансе — малые p и предупреждение в ленте задолго до (пожарные 0% в городе с домами = событие-намёк).
