# EPIC-18: Туториал v2

Issue: #18 · Ярлык: ux · Зависимости: EPIC-13 (подсветка кнопок панели), EPIC-02 (больница/парк как финал цепочки) · Заменяет `StartHintPolicy`/`StartHintView` (задачи 097)

## Проблема

Стартовая подсказка ведёт только до первого дома («зоны → рост → первый дом») и гаснет. Дальше новый игрок один: не знает про энергию/воду/мусор (задача 093 показала — без станций город стоит), про службы, про налоги.

## Что увидит игрок

Цепочка подсказок на ~10 минут, каждый шаг — одно действие игрока (правило видимости системы):
1. «Закрась 4x4 жилой зоны» → подсветка кнопки Зоны;
2. «Включи рост» → подсветка Роста;
3. «Дождись первого дома»;
4. «Построй электростанцию» → подсветка Строить → палитры;
5. «Построй водонапорную башню»;
6. «Построй мусорный полигон»;
7. «Построй парк — людям приятнее жить» (после EPIC-02);
8. Готово: «Дальше сам. Цель: 50 жителей».
Шаг с номером и текстом показывается у нижней панели; нужная кнопка подсвечивается рамкой; кнопка «Понятно» гасит туториал навсегда (для ветеранов).

## Архитектурный план

- `Scripts/UI/TutorialPolicy.cs` (plain C#): упорядоченные шаги `TutorialStep { id, text, targetButton }`, условие перехода — предикат по снимку состояния (зоны закрашены ≥ 16 клеток, рост включён, grown ≥ 1, станции Power/Water/Waste стоят, парк стоит). Тот же стиль, что `StartHintPolicy` (тестируемая чистая логика), но многошаговый.
- `TutorialView.cs` (IMGUI): строка шага над нижней панелью (позиция из `HudLayout`), подсветка кнопки — рамка-прямоугольник поверх rect из `HudLayout` (единственный источник геометрии), кнопка «Понятно».
- `StartHintPolicy/View` удаляются (их роль забирает туториал); их тесты переписываются на новую политику честно, без ослабления.
- Состояние туториала не сериализуется: после загрузки сейва туториал считается пройденным (кто сохраняется — уже играет); «Новая» запускает заново. Упрощение зафиксировать.
- Инкремент «grown ≥ 1» и «станции стоят» — из существующих снимков (`ManualBuildingsStore`, grown-счётчик), новых запросов в домен не заводить.

Что НЕ делаем: видео/стрелки, сценарные диалоги, награды за шаги, шаги про налоги/пробки (за пределами первых 10 минут).

## Шаги

1. **policy-steps** — `TutorialPolicy` (шаги + предикаты) + полная матрица тестов; удаление `StartHint*`, перенос тестов.
2. **view-highlight** — `TutorialView` + подсветка кнопок нижней панели + «Понятно»; E2E всей цепочки.

## План тестов

- Матрица переходов: каждый шаг наступает ровно при своём предикате; пропуски шагов невозможны; из середины (симуляция «построил всё сразу») цепочка схлопывается в конец без застревания.
- «Понятно» гасит навсегда в сессии; «Новая» возвращает.
- Старые тесты `StartHintPolicy` переписаны на `TutorialPolicy` 1-в-1 по смыслу.

## Unity-приёмка (E2E)

Новый город → пройти цепочку как новичок, каждый шаг подсвечивает правильную кнопку; нажать «Понятно» на шаге 4 → больше не появляется; сейв/лоад → туториала нет. Скриншот шага с подсветкой. Консоль чистая.

## Критерий закрытия эпика

Новый игрок доходит до парка/служб за ~10 минут без внешних подсказок; ветераны отключают одним кликом; тесты зелёные.

## Запрещено / риски

- Подсветка — только по rect из `HudLayout`: если кнопка не найдена (макет изменился), туториал рисует текст без рамки, а не падает.
- Риск: предикаты шагов завязаны на ещё не готовые эпики (парк) — шаги 7+ включаются флагом наличия определения в палитре (парк не разблокирован/нет ассета → шаг пропускается).
