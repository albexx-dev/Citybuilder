# EPIC-15: Пробки глазами игрока

Issue: #15 · Ярлык: ux · Зависимости: `CongestionSystem`/`CongestionController` (есть с задач 057/067); визуально связан с EPIC-12 (подсветки) и EPIC-14 (строка в меню)

## Проблема

Пробки считаются и влияют на рост (`GrowthTickMultiplier`, задача 067), но игрок их не видит: дороги выглядят одинаково и при свободном движении, и при заторе. Единственный сигнал — замедление роста без причины.

## Что увидит игрок

Дороги окрашиваются по нагрузке: свободная клетка — обычный асфальт, средняя — желтеет, плотная — краснеет. В инфоменю (EPIC-14) — строка «Пробки: N (худшая клетка Z%)» и множитель роста от пробок. Игрок видит затор и строит дорогу-дублёр — краснота уходит.

## Архитектурный план

- Запрос нагрузки: `CongestionSystem` получает `Load01(GridPosition)` (сейчас нагрузка клеток есть внутри — проверить accessor; если нет, добавить чистый запрос по снимку, домен не меняет правила).
- Перекраска: `RoadView`/`RoadNetworkStore` — цвет клетки через `MaterialPropertyBlock` (без инстансов материалов): lerp зелёный→жёлтый→красный по Load01; пороги 0.33/0.66. Обновление цвета — раз в тик по подписке контроллера, не каждый кадр.
- Легенда: строка в инфоменю; при выключенном EPIC-14 — временная строка HUD рядом со связностью.
- Статус роста: причина «пробки» уже называться (`GrowthStatusPolicy`) — сверить формулировку с новой видимостью.

Что НЕ делаем: машины/анимация движения (транспорт с машинами — только через ADR), изменение расчёта пробок, перекраска зданий.

## Шаги

1. **load-query** — `Load01(cell)` в `CongestionSystem` + тесты (пустая дорога 0, перегруженная 1, промежуточные).
2. **road-recolor** — перекраска в `RoadView` раз в тик; тесты порогов цвета (чистая математика lerp/порог); E2E «25 поездок → дороги краснеют» (сценарий задачи 067).
3. **hud-line** — строка «Пробки» в меню/временный HUD; свертка с `GrowthStatusPolicy`.

## План тестов

- `Load01`: границы 0/1, NaN → 0 (нейтраль, паттерн 084).
- Порог перекраски: 0.32 зелёный, 0.34 жёлтый, 0.65 жёлтый, 0.67 красный (чистая функция цвет → тест).
- Обновление раз в тик: двойной вызов за кадр не дублирует работу (счётчик в тестовом двойнике).

## Unity-приёмка (E2E)

Город с 25+ поездками (сценарий из задачи 067): дороги у полосы нагрузки жёлтые/красные; построить дублёр — покраснение спадает за тики; строка пробок совпадает с множителем роста. Скриншот перекрашенной дороги. Консоль чистая.

## Критерий закрытия эпика

Нагрузка дороги видна цветом, числа в меню сходятся с множителем роста, обновление дешёвое (раз в тик), тесты зелёные.

## Запрещено / риски

- Не менять `GrowthTickMultiplier` и правила расчёта — только доступ к данным и визуал.
- Риск перфа: перекраска каждой клетки каждый кадр запрещена — строго раз в тик и только изменившихся клеток (сравнение с прошлым значением).
