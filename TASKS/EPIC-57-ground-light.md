# EPIC-57: Земля и свет — трава, мягкое освещение, рамка карты

Issue: #57 · Ярлык: content · Зависимости: #54 (стиль); основа для #58 (день/ночь)

## Проблема

Земля — плоская серая подложка, свет — дефолтный DirectionalLight без теней, край карты ничем не ограничен визуально. Скриншоты выглядят как редактор, не как игра.

## Что увидит игрок

Трава с вариацией оттенков (не однотонная), мягкий солнечный свет с тенями от зданий, край мира — полоса воды/песка (Kenney). Сетка линий приглушена и не спорит с городом.

## Архитектурный план

- Земля: `GridGroundBuilder` (Presentation) — один меш земли под сеткой с vertex-color вариацией травы (без текстур 4K; Kenney ground — опционально) + приглушение линий сетки (`GridMeshBuilder` — цвет линий прозрачнее).
- Свет: настройки DirectionalLight (угол, intensity, Soft Shadows) — фиксированные «хорошие» значения в сцене; основа для #58 (контроллер дня/ночи будет двигать ЭТОТ свет).
- Рамка карты: полоса «воды/песка» вокруг 50×50 (один меш-бампа, view-слой) — визуальный край без изменения домена.
- Всё — Presentation: домен не трогается, существующие тесты не правятся.

## Шаги

1. **ground** — меш земли + вариация + приглушение сетки + скриншот.
2. **light** — свет/тени в сцене (правки сцены через мост, единственная сцена) + приёмка.
3. **border** — рамка карты (вода/песок) + перф (1 draw call).

## План тестов

- Чистая математика не меняется — тесты зелёные без правок.
- Валидатор: сцена не «грязная» после правок (мерж оркестратором по чек-листу).

## Unity-приёмка (E2E)

Скриншот до/после с той же камерой; FPS-замер (тени на 80 зданиях);Play-E2E без регрессий (рост/постройка). Консоль чистая.

## Критерий закрытия эпика

Скриншот выглядит как игра; FPS в лимите; свет готов как основа #58.

## Запрещено и риски

- Никакого post-processing стека (URP-пакеты запрещены scope lock) — только built-in: light/shadow/материалы.
- Риск: тени на 2500 линиях сетки — линии без cast shadows.
