# EPIC-19: Звук (опционально)

Issue: #19 · Ярлык: ux · Статус: опциональный — может быть отложен владельцем без ущерба релизу · Только встроенный Unity Audio, БЕЗ новых пакетов

## Проблема

Игра полностью беззвучна: клики, деньги, события — всё молчит. Полировка продукта, заметная с первых секунд.

## Что услышит игрок

- клик по любой кнопке UI — короткий «тик»;
- сбор налога в час — мягкий «коин» (не каждый тик — утомит; раз в игровой час при ненулевом сборе);
- событие в ленте (EPIC-09) — тихий «поп»;
- открытие/закрытие меню — лёгкий свуш;
- общий громкости-слайдер + чекбокс «Без звука» в пауза-меню (EPIC-16).

## Архитектурный план

- `Scripts/Presentation/AudioController.cs` (тонкий MonoBehaviour): 1 AudioSource для UI; методы `PlayClick()`, `PlayCoin()`, `PlayPop()`, `PlaySwoosh()`; вызовы из view-слоя (BottomBarView, InfoMenuView, EventLogView, TreasuryView-событие).
- Клипы: `Assets/Citybuilder/Audio/` — 4-5 коротких WAV. Источник: бесплатные CC0 (freesound/Kenney) или сгенерированные скриптом синты — лицензия фиксируется в файле `Audio/LICENSE-NOTES.md`. Никаких сторонних аудио-пакетов (запрещено scope lock).
- Громкость: `AudioListener.volume` из пауза-меню; значение хранится в `PlayerPrefs` (встроенное, не городское состояние — в сейв не попадает).
- Всё выключено по умолчанию? Нет: тихая громкость 0.5 по умолчанию, выключается слайдером.

Что НЕ делаем: музыка/эмбиент (отдельное решение владельца), 3D-звуки города, сжатие/банки, микшеры AudioMixer (лишняя сущность для 4 звуков).

## Шаги

1. **audio-core** — `AudioController` + 4 клипа + вызовы из 4 точек UI; слайдер в паузе.
2. **polish** — калибровка громкостей (клик тише коина), лицензионные заметки.

## План тестов

- Домен звука не касается — тесты только на факт: вызовы view не падают при отсутствии AudioSource/клипов (null-гвард, игра молчит, не крашится).
- PlayerPrefs: громкость 0..1 клампится.

## Unity-приёмка (E2E)

Пройти клики/налог/ленту на слух; слайдер на 0 — тишина; перезапуск — громкость запомнилась. Консоль чистая.

## Критерий закрытия эпика

4 звука на месте, громкость управляется и запоминается, лицензии чистые, домен не тронут.

## Запрещено / риски

- Любые сторонние аудио-пакеты — запрещены; только клипы-файлы.
- Риск утомительности: «коин» каждый час при x4 — раз в минуту реального времени; если раздражает — оставить только UI-звуки (решение на E2E, зафиксировать).
