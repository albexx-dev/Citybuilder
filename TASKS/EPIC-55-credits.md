# EPIC-55: CREDITS.md + лицензионная гигиена ассетов

Issue: #55 · Ярлык: content · Зависимости: #54 (модели), валидатор

## Проблема

Репо MIT + публичный релиз с билдом: сторонние ассеты (Kenney, будущие Sketchfab CC-BY, шрифты, звуки) не «покрываются» MIT. Ни одного файла-реестра нет — юридическая дыра при распространении.

## Что увидит игрок

Ничего (в игре — окно «Об игре» с благодарностями — опциональный шаг). главное — чистота релиза для незнакомцев иcontributors.

## Архитектурный план

- `CREDITS.md` в корне: таблица `Ассет | Автор | Лицензия | Источник | Файлы` — по каждому стороннему файлу в `Assets/` и `Tools/` (звуки EPIC-19 procedural — собственные, но фиксируются).
- Валидатор: расширить `Tools/ValidateRepo.py` — каждый файл в `Assets/Citybuilder/Models/<Vendor>/` и `Audio/` должен быть покрыт строкой в CREDITS (проверка префиксов пути по реестру).
- README: секция «Credits» со ссылкой.
- Лицензия самого репо (MIT) дополняется абзацем «third-party assets — see CREDITS.md».

## Шаги

1. **credits-file** — `CREDITS.md` с текущими ассетами (Kenney City Kit Commercial — building-a, hospital/park — собственные Blender, звуки EPIC-19).
2. **validator-guard** — проверка покрытия в `ValidateRepo.py` + тест кейсы.
3. **readme** — секция в README + строка в LICENSE-примечании.

## План тестов

- Валидатор: модель без записи в CREDITS → fail; запись есть → OK.
- Все существующие сторонние файлы покрыты.

## Unity-приёмка (E2E)

Нет (док-эпик): валидатор зелёный, README рендерит таблицу.

## Критерий закрытия эпика

Каждый сторонний ассет прослеживается до лицензии; валидатор охраняет реестр.

## Запрещено и риски

- Не добавлять ассеты без записи в CREDITS — валидатор теперь это ловит.
- Риск: записи «на память» без точного URL — только проверяемые источники.
