# EPIC-16: Главное меню + пауза-меню

Issue: #16 · Ярлык: ux · Зависимости: EPIC-11 (слоты для «Продолжить»), EPIC-13/14 (стиль панелей); минимальная версия возможна и до EPIC-11 с одним слотом

## Проблема

Главное меню — IMGUI-кнопки в углу поверх живого города (задача 046), пауза — только кнопка скорости. Старт/выход ощущаются прототипом; «Продолжить» нет, выхода в главное меню из игры нет.

## Что увидит игрок

**Главное меню** — затемнение поверх живого (пауза) города, панель по центру: Продолжить (последний слот), Новая игра, Загрузить (слоты EPIC-11), Выход.
**Пауза-меню** — Esc в игре: затемнение + Продолжить, Сохранить (слоты), Загрузить, В главное меню. Город на паузе, ввод в мир заблокирован, повторный Esc — продолжить.

## Архитектурный план

- `Scripts/UI/MainMenuView.cs` — переработка: полноэкранное затемнение + центральная панель (подложки `HudText`), кнопки шлют существующие команды (`NewGame` из задачи 046, загрузка из EPIC-11).
- `Scripts/UI/PauseMenuView.cs` (новый): состояние Paused в `SimulationRunner` уже есть — меню вызывается по Esc через `BuildModeHotkeys`-паттерн (глобальный хоткей с `UiClickGuard`); при открытом меню: снимок экрана затемняется GUI-прямоугольником, клики в мир гардятся (регистрация полноэкранного rect).
- «В главное меню»: город НЕ сбрасывается молча — если с последнего сейва были изменения, подтверждение «Сохранить перед выходом? Да/Нет/Отмена» (состояние «грязный город» — флаг в `SaveController`, инкрементируется командами изменения мира; минимально: любой BuildMode-действие после последнего сейва).
- Фон: сцена продолжает рендериться (живой город на паузе) — отдельная сцена меню НЕ заводится (одна игровая сцена — стандарт AGENTS.md).

Что НЕ делаем: настройки графики/звука (звук — EPIC-19, громкость туда), анимации переходов, вторая сцена.

## Шаги

1. **pause-menu** — `PauseMenuView` + Esc-хоткей + гарды + «грязный город»-флаг; E2E.
2. **main-menu-rework** — затемнение/панель/Продолжить (слот 0 или последний из EPIC-11); E2E цикла меню→игра→меню.
3. **exit-confirm** — подтверждение выхода с несохранённым; тесты флага грязности.

## План тестов

- «Грязный» флаг: NewGame → чистый; построил дом → грязный; SaveNow → чистый; Load → чистый.
- Esc-логика: открыто меню → Esc закрывает; закрыто → Esc открывает; открытое меню блокирует BuildMode-хоткеты (1-4 не работают).
- Переходы: после «В главное меню» город остаётся в состоянии последнего действия (не сбрасывается), «Новая» сбрасывает по правилам задачи 046 (0/0/1000/0 + налог обычный).

## Unity-приёмка (E2E)

Полный цикл: меню → новая → построил → Esc → сохранить в слот 1 → в главное меню → Продолжить (слот 1) → город вернулся; Esc на каждом шаге ведёт себя предсказуемо. Скриншоты обоих меню. Консоль чистая.

## Критерий закрытия эпика

Старт/пауза/выход — цельные экраны, несохранённый прогресс защищён подтверждением, хоткеты не конфликтуют, тесты зелёные.

## Запрещено / риски

- Не заводить вторую сцену и GameState-синглтоны (запрещены ARCHITECTURE) — меню это view поверх существующих команд.
- Риск Esc-войны между паузой и режимом Выкл: приоритет — пауза перехватывает Esc первой и глушит остальные хоткеты (порядок подписок зафиксировать тестом).
