# TASKS/001 — Project Foundation

## Цель

Зафиксировать правила проекта и документацию. Без игровой механики.

## Контекст

Этап 0 из ARCHITECTURE.md. Репозиторий содержит только README, LICENSE, .gitignore. Локальный Unity-проект пока отделён.

## Что нужно сделать

1. Создать AGENTS.md (правила Architect/Engineer, лимиты файлов, workflow).
2. Создать ARCHITECTURE.md (модули, Definition/State/View, тики, команды, сетка).
3. Создать GAME_DESIGN.md (фэнтези, цикл, срез прототипа).
4. Создать TASKS/README.md (очередь 001–008 со статусами).
5. Ветка task/001-project-foundation, коммит, PR, мерж в main.

## Что не нужно делать

- Не писать Grid, строительство, экономику, жителей, дороги, UI-код.
- Не создавать папки Assets впрок без кода.
- Не менять ProjectSettings, не добавлять пакеты.
- Не трогать задачи 002+.

## Зависимости

Нет. Это первая задача, остальные зависят от неё.
