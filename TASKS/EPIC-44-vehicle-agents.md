# EPIC-44: Машины-агенты — поездки дом→работа по дорогам

Issue: #44 · Ярлык: mechanics · ADR: **ADR-011 (до кода)** · Зависимости: `RouteSystem`/`CongestionSystem` (v1.1); модели — #60; перф — #62

## Проблема

Дороги и пробки считаются абстрактно (нагрузка клеток), по улицам ничего не ездит — главный источник «живости» отсутствует. Запрет «транспорт с машинами» из scope lock v1.1 снимается эпиком v1.2 через ADR-011.

## Что увидит игрок

Утром от домов к магазинам/фабрикам едят машины, вечером возвращаются. Поток виден глазами; пробки на красных дорогах физические (см. #45).

## Архитектурный план (фиксируется ADR-011)

- `Scripts/Simulation/AgentManager.cs` (plain C#, единый для агентов v1.2): пул агентов, лимит `MaxAgents` (дефолт 40), спавн/деспавн без GC-давления.
- `VehicleAgent` (struct/класс в менеджере): маршрут из `RouteSystem.FindPath(дом → рабочее место)`, прогресс по клеткам, состояние (в пути/на месте/возвращается).
- График спавна: по игровому часу — утром (7:00–9:00) спавн дом→работа, вечером (17:00–19:00) работа→дом; агент исчезает по прибытии.
- `VehicleAgentView` (Presentation): пул визуальных машин (модели — #60), позиция из агента; машина без вида при лимите вида (agent живёт, view по приоритету близости к камере — см. #62).
- Связь с доменом: каждая активная поездка = 1 «поездка» в `CongestionSystem` (см. #45; сейчас поездки синтетические — замена, не дублирование).
- Сейв: агенты НЕ сериализуются (пересчитываются от домов/работ).

## Шаги

1. **adr-agents** — ADR-011 в `DECISIONS/`.
2. **agent-core** — `AgentManager` + `VehicleAgent` + маршруты + тесты (пул/лимит/прибытие).
3. **agent-view** — `VehicleAgentView` + пул видов + интеграция в сцену (объект Simulation).
4. **trips-wire** — замена синтетических поездок в `CongestionController` на агентные; тесты на эквивалентность нагрузки.

## План тестов

- Пул: спавн до лимита, деспавн по прибытии, повторный спавн переиспользует слоты.
- Маршрут: при отсутствии пути агент не спавнится (тихий пропуск), путь через дорогу-дублёр меняется.
- Часы: спавн только в утренние/вечерние окна; пауза замирает агентов.
- Нагрузка: клетки под машинами получают ту же нагрузку, что старый синтетический расчёт (тест-эквивалентность).

## Unity-приёмка (E2E)

Город 15+ домов с дорогами: x4 → утром поток машин к коммерции, вечером обратно; пауза замирает; снос дороги перестраивает маршруты (событие/видимость). Скриншот потока. Консоль чистая, тик ≤5 мс (профайлер).

## Критерий закрытия эпика

Машины ездят по расписанию суток, маршрут живой при изменении дорог, пул без утечек, тесты зелёные.

## Запрещено и риски

- Без ADR-011 не начинать. Никаких Jobs/Burst/async (запреты AGENTS.md).
- Риск перфа: виды машин без пула = мусор GC. Пул обязателен в первом шаге.
- Физика поездок упрощённая (позиция по клеткам), не Rigidbody — иначе перф.
