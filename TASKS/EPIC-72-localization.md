# EPIC-72: Локализация EN (опционально)

Issue: #72 · Ярлык: ux · Статус: опциональный — откладывается без ущерба релизу · Зависимости: #66 (реестр `UIText`)

## Проблема

Все строки UI/туториала/квестов/ленты — русские, захардкоженные в view-классах. Английская версия недоступна (а это международный GitHub).

## Что увидит игрок

Настройка «Язык: RU/EN» — весь интерфейс мгновенно переключается: кнопки, тултипы, туториал, квесты, лента, настройки. HUD-строки — тоже (форматирование через реестр).

## Архитектурный план

- `Scripts/Core/Localization.cs` (plain C#): словарь `ключ → {ru, en}`, `Localization.Get(key)`; язык — в `GameSettings` (#69), событие смены языка.
- Миграция: все строки view-классов → ключи `UIText`/`Localization` (механическая, но объёмная замена — список файлов: BottomBarView, InfoMenuView, все Views, TutorialPolicy, QuestCatalog, CityEventLog-сообщения, HudText-строки).
- Форматирование с числами: паттерны строк («Пожарные: {0}/{1} ({2}%)») — плюрализация по-английски простая.
- Никаких сторонних локализационных пакетов (запрещены) — свой словарь.

## Шаги

1. **loc-core** — `Localization` + событие смены + тесты (fallback на RU при отсутствии EN).
2. **strings-migration** — перенос строк по списку файлов (несколько шагов по блокам UI).
3. **en-translation** — перевод всех ключей + переключатель в настройках.

## План тестов

- Fallback: ключ без EN → RU строка; ключ вообще без записи → сам ключ (не краш).
- Смена языка на лету: все зарегистрированные views перерисовались (список слушателей).

## Unity-приёмка (E2E)

Переключение RU↔EN на лету: панель/инфоменю/туториал/квесты/лента — всё на выбранном языке; перезапуск — язык сохранён. Скриншоты обеих локалей.

## Критерий закрытия эпика

Ни одной захардкоженной строки в UI; EN полный; переключение мгновенное.

## Запрещено и риски

- Сторонние i18n-пакеты — запрещены.
- Риск объёма: миграция строк — чёткий чек-лист файлов, делать блоками по 1 коммиту.
- Эпик опционален: может откладываться владельцем без ущерба релизу #73.
