# TASKS/100-breakdown — налоги наглядны (пункт 6 чек-листа 093)

Дата: 26.10.2026. Ветка: task/100-tax-income. Модуль: Economy + UI.

## Ввод
Кнопка «Налог: обычный (2)» показывает ставку, но не эффект. Игрок жмёт её и не видит, что изменилось: доход капает по тикам в общую казну и теряется среди трат на рост.

## Действие игрока
Навести взгляд на кнопку налога — рядом с уровнем виден фактический сбор: «Налог: обычный (2) +4 $/ч». Переключить уровень — сумма меняется на «+2»/«+6»; появились работающие — сумма выросла без переключения.

## Шаги
- [x] `TaxPolicy.Income(employed)` — ставка × работающие, чистая логика.
- [x] `TaxSystem.Employed` — сколько реально платит, через существующую занятость.
- [x] `TaxPolicyView` — суффикс « +N $/ч» в подписи кнопки, ссылка на `EconomyTicker`.
- [x] Тесты `TaxPolicyTests` — доход на трёх уровнях и при нуле работающих.
- [x] Play-E2E: жители + работа → в подписи ненулевой доход; переключение уровня меняет сумму; Console чистый.

## Лимиты
Файлы ≤150 (TaxPolicy 93 → ~100, TaxPolicyView 36 → ~65, TaxSystem 46 → ~50).
