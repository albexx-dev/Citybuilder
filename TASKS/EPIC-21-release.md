1. **freeze-and-sweep** — стоп новых фич; прогон валидатора/тестов; добивка хвостов доков.

3. **release-publish** — GitHub Release с артефактом, README-скриншоты, закрытие версии.

## План тестов

- Полный EditMode прогон + `dotnet`-прогон чистой логики (по процессу AGENTS.md).
- Smoke-чек-лист билда: новая игра → зоны → рост → станции → службы → сейв/лоад слот 1 → автосейв → лента → инфопанель → пауза → выход. Письменный отчёт.

## Unity-приёмка (E2E)

30-минутная сессия в финальном билде по сценарию EPIC-06 + все UI-экраны. Скриншоты в `Screenshots/` для README.

## Критерий закрытия эпика

Release опубликован, незнакомец скачивает и играет, доки описывают код, версия закрыта. После этого — планирование v1.2 (пожары #7, машины, прочее) новым листом.

## Запрещено / риски

- Не публиковать Release с красным CI или грязной консолью билда.
- Риск «ещё одну фичку перед релизом» — запрет: после freeze только фиксы.
