# ADR-010: Источники ассетов, масштаб и полигонаж

Date: 2026-11-15. Status: accepted.

## Context

v1.1 оставила здания кубами-примитивами, кроме пилота (task/161: Shop = Kenney building-a, CC0). v1.2 заменяет все 10 типов на модели. Нужны правила: откуда брать ассеты, как вписывать в сетку 1×1 м (ARCHITECTURE §7 — Locked V1), лицензии публичного MIT-репо и релиза.

## Decision

- **Источники:** Kenney (CC0) — базовый поставщик (City/Industrial/Nature/Vehicle/UI kits, скачивание через браузер). Sketchfab — только модели с лицензией **CC0 или CC-BY** и только low-poly отдельными файлами. Модели «Editorial/Personal use» запрещены.
- **Лицензии:** каждый сторонний файл фиксируется в `CREDITS.md` (эпик #55); валидатор проверяет покрытие. CC-BY требует указания автора — обязательно в CREDITS.
- **Масштаб:** модель вписывается в `Footprint` здания по XZ (дом 2×2 м и т.д.), пивот — в основании по центру. Высота — пропорциональна, не лимитируется жёстко (дома ≤2.5 м, службы ≤3 м, фабрики ≤4 м).
- **Полигонаж:** ≤3k треугольников на здание (Kenney киты дают 200–1500 — запас); транспорт ≤800; декор ≤300.
- **Текстуры:** атлас кита рядом с моделью; PNG идут через Git LFS (настроено), FBX — напрямую в git (решение EPIC-20).
- **Конвейер:** проверен пилотом task/161 — импорт FBX в `Assets/Citybuilder/Models/<Vendor>/`, префаб с масштабом/пивотом, привязка к `BuildingDefinition.Prefab`, меты, коммит.
- **Стиль:** один кит на тип здания; не смешивать hi-poly и low-poly.

## Consequences

- Публичный релиз юридически чист (CREDITS-реестр охраняется валидатором).
- Замена модели = замена префаба, домен не трогается.
- LFS-квота GitHub расходуется на атласы — держать только нужные PNG.
