# ADR-012: Квесты-вехи — бесконечные цепочки задач с наградами

Date: 2026-11-15. Status: accepted.

## Context

Цель со ступенями 50/100/200 — линейка, после 200 игрок без ориентиров. Доктрина «игра без конца» запрещает финал — нужны бесконечно генерируемые вехи с наградами.

## Decision

- **`QuestDefinition`** (plain C# struct): `Id`, `Title`, `Description`, `IsSatisfied` (Func<QuestContext, bool>), `Reward` (int).
- **`QuestCatalog`** (static): 10 стартовых квестов поверх существующих систем; генератор следующих вех по прогрессу города.
- **`QuestSystem`** (plain C#): активные 3 задачи + выполненные (id-список), `Claim(goals, stages, treasury, coverage)` — проверка, начисление, генерация следующей.
- **Сейв**: активные + выполненные id — снапшот v5.
- **UI**: `QuestLogView` (кнопка в нижней панели) — 1–3 задачи с прогрессом и наградой.
- **Награда**: казна (Treasury.Earn), событие в ленту.

## Consequences

- Тесты: переходы, неповторы, границы (0 зданий → недоступные квесты скипаются).
- Доктрина сохранена: квесты не создают конца игры.
