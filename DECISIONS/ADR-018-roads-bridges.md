# ADR-018: Дороги и мосты — уровень в ключе клетки, съезды и совместимый сейм

Date: 2026-11-26. Status: accepted.

## Context

Issue #154 (эпик v1.4.5, «ADR до кода»). `AGENTS.md:128` прямо запрещает многоуровневость без ADR; по `AGENTS.md` новый архитектурный паттерн внутри эпика фиксируется до первого шага с кодом.

Разведка: `RoadDefinition` хранит только `Id`/`DisplayName`/`CostPerCell` (плюс `Category`), `RoadState` — `Id` + `Cell`, `GridPosition` — `X`/`Y` без высоты, `RouteSystem` ищет путь A* по 4 соседям в плоскости `GridPosition`, `CitySnapshot.RoadEntry` — `{X, Y}`. Типа «мост» и второго яруса нет: дорога занимает клетку один раз, перекрытие невозможно.

Действие игрока: построить мост через канал и провести под ним обычную дорогу; машина едет по верхнему полотну, нижняя дорога остаётся на месте и доступна маршруту, а старый слот с обычными дорогами грузится без изменений.

## Decision

- **Снятие запрета — только для дорог.** Запрет многоуровневости `AGENTS.md:128` снимается исключительно для дорог и мостов. Здания, зоны, сети, агенты и остальные пункты строки 128 (транспорт с машинами, облачные сейвы, Jobs/Burst, DI-контейнеры, async/await, новые пакеты, UI Toolkit) остаются под запретом. Правку самой строки 128 вносит оркестратор централизованно, не этим шагом.
- **Четыре типа дорог.** Две обычные — `asphalt` и `brick`: уровень 0, занимают клетку как сегодня. Два моста — `wood` и `stone`: полотно на уровне ≥1, под ним сохраняется клетка уровня 0. Четыре `RoadDefinition` с Id латиницей; новых глобальных синглтонов не вводится.
- **Ключ клетки и occupation.** `GridPosition` не меняется (`X`/`Y`, без высоты — не ломает зоны, здания и существующие тесты). Вводится составной ключ `RoadCellKey(X, Y, Level)` (plain C#); occupation дорог хранится по этому ключу, на одной `(X,Y)` допустимы записи level 1 и level 2. Level — неотрицательное целое, 0 по умолчанию; мост ставится на level 2, уровни ≥2 зарезервированы и в этом эпике не строятся. Повторная укладка в занятый ключ не создаёт дубля; снос моста освобождает только его level и не трогает дорогу под ним. Мост нельзя ставить поверх здания или зоны.
- **A*-соседи и съезды.** Обычные дороги не требуют изменений `RouteSystem`: level не участвует, поведение совпадает с текущим. Для мостов A* работает в пространстве ключей: 4 соседа на том же level плюс явные съезды (ramp) — вертикальные переходы 1↔2 в клетках-концах моста. `IsRoad` проверяет тот же level, поэтому маршрут с моста не «проваливается» на дорогу под ним без съезда; мост без съезда — тупик. Приоритет при показе и выборе: верхний level (мост) доминирует визуально, нижний остаётся в occupation, в сейме и доступен маршрутам level 1; снятие моста восстанавливает нижнюю дорогу без пересчёта.
- **Сейм и обратная совместимость.** `RoadEntry` получает опциональные `Type` (Id типа) и `Level` (int). Fallback: пустой или неизвестный `Type` → `asphalt`, отсутствующий `Level` → `0`; старые записи `{X,Y}` читаются как `asphalt` level 1 и ведут себя как сегодня. Версия снимка **не меняется до ADR-022** (остаётся 6); совместимость v1–v6 сохраняется, v7 зарезервирован за отдельным ADR. Экспорт/импорт идут по правилам ADR-014/ADR-016: тот же JSON `CitySnapshot` v6, тот же `SaveSlotStorage`, без нового сериализатора, reflection, ручного JSON и облачных сейвов. Нормализация без исключений: некорректный `Type` или `Level` вне диапазона 1..3 → дефолт, дубли по `(X,Y,Level)` дедуплицируются (остаётся последний), неизвестная версия > 6 — ошибка валидации, не тихий даунгрейд; старые файлы не переписываются до явного сохранения.
- **Ограничения.** Модели дорог и мостов — по ADR-010: ≤3k треугольников на модель, Kenney (CC0) или CC-BY low-poly отдельными файлами, запись в `CREDITS.md`, FBX в git, PNG через LFS, один кит на тип, без смешивания hi-poly и low-poly. Built-in Render Pipeline (не URP), UI только на IMGUI (не UI Toolkit). Сцена, Unity и снимок в этом шаге не трогаются.

## Consequences

- ADR принят до первого кода дорог: последующие шаги эпика идут по ≤5 файлов и ≤250 строк с ревьюером после каждого; этот шаг — только новый файл ADR.
- Тесты последующих шагов: occupation для двух level, идемпотентная укладка и снос только своего level, A* по мосту и съездам без «провала» на нижнюю дорогу, приоритет моста при показе, round-trip `{X,Y}` → `{Type,Level}` и обратно, битые и дублирующиеся `RoadEntry` при загрузке и импорте, совместимость v1–v6.
- Игрок видит мост с дорогой под ним: верхний маршрут работает, нижний не стирается, старые слоты не ломаются.
- Документы (`AGENTS.md`, `ARCHITECTURE.md`, `CHANGELOG.md`) обновляет оркестратор централизованно; этот шаг их не трогает.
- Границы: здания, зоны и сети остаются одноуровневыми; агенты и пожары не сериализуются (ADR-009/011/014); уровни ≥2 и bump версии снимка — после ADR-022; без чисел Profiler никаких perf-правок (ADR-001/016).
