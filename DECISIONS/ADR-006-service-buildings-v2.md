# ADR-006: Обобщённая система служб (ServiceBuildingSystem v2)

Date: 2026-11-08. Status: accepted.

## Context

Пожарные и полиция реализованы параллельными контроллерами: `FireCoverageController` строит снимок покрытия по виду службы (`ServiceKind`), но каждый новый вид службы означает ещё один контроллер с той же логикой радиуса и снимков. В v1.1 добавляются больница (здоровье) и парк (досуг) — без обобщения это четыре копии одного паттерна.

## Decision

Один plain C# `ServiceBuildingSystem` со `ServiceKind` (Fire/Police/Health/Leisure):

- источники — обычные `BuildingDefinition` с полями `ServiceKind` + `ServiceRadius` (расширение существующего ScriptableObject, новых типов данных нет);
- система строит снимок покрытия по всем видам и отдаёт `Coverage01(kind, cell)` / покрытие по домам;
- `FireCoverageController` и контроллер полиции мигрируют на общую систему и сливаются в один адаптер;
- `NeedSystem` читает здоровье и досуг из покрытия (`NeedProviders` расширяется до 0..6);
- строки HUD служб читают один источник вместо двух.

## Consequences

- Минус ~400 строк дублей; новая служба = ассет + значение enum.
- Существующие тесты пожарных/полиции рефакторятся на общую систему без потери покрытия.
- Ручная установка станций (`ManualBuildingsStore`) продолжает работать через тот же Definition-механизм.
- Реализация идёт эпиком (GitHub Issues), шаги — по обычному циклу с ревьюером.
