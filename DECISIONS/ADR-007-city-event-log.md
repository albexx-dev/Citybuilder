# ADR-007: Событийная лента города (CityEventLog)

Date: 2026-11-08. Status: accepted.

## Context

Причины состояний игрок не видит: дефицит снабжения, пробки, безработица проявляются только цифрами в HUD. Архитектура запрещает глобальную шину событий, и отдельного места для «что случилось в городе» нет. При этом ADR-005 требует, чтобы документация описывала код, а не намерения — паттерн фиксируется этим ADR до реализации.

## Decision

Plain C# `CityEventLog` — append-only кольцо последних 50 событий:

- запись `Add(kind, message, tick)` выполняют контроллеры на границе тика (домен не знает про Unity-события);
- единственный подписчик — `EventLogView` (IMGUI): по запросу берёт снимок ленты и рисует строки через существующий паттерн `HudText`;
- глобальная шина не вводится, новых Unity-событий в домене нет;
- лента не сериализуется в сейв (только текущая сессия).

## Consequences

- Игрок видит причины: «Энергия 46% — рост замедлен», «Высокая безработица».
- Сообщения на русском, форматирование — в view-слое.
- Публичные службы сообщают о дефиците/покрытии через тот же лог.
