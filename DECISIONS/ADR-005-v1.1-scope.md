# ADR-005: v1.1 scope

Date: 2026-11-08. Status: accepted.

## Context

Tasks 001–104 produced a playable prototype: 50×50 grid, zones, tick-based growth, population, taxes, energy/water/waste, fire/police coverage, road connectivity and congestion, goal stages 50/100/200, save/load snapshot v4, HUD hints and manual service buildings. The old `HANDOFF.md` described a chat-to-chat continuation process and had drifted from the code. ADR-004's "frozen until release" clause was lifted by its post-release amendment after task 047.

## Decision

Start the **v1.1** line from the task-104 state.

- `HANDOFF.md` is removed. `README.md` is the entry point, `AGENTS.md` holds working rules, `TASKS/README.md` holds the queue, `CHANGELOG.md` holds version history, `DECISIONS/` holds architecture decisions.
- v1.1 includes everything already implemented in 001–104. It does **not** reintroduce win/lose screens; `GoalSystem.Won/Lost` is retained deliberately as tested domain logic for a later version.
- The minimal-release freeze in ADR-004 stays historical. Current boundaries are `AGENTS.md` → Scope lock plus this ADR.
- Still forbidden without a new ADR: vehicle transport, multi-level construction, cloud saves, Jobs/Burst, DI containers, `async/await`, new third-party packages.
- CI, portable paths, release tags and branch protection become part of the normal workflow.

## Consequences

- Documentation must describe the code, not an aspirational architecture.
- Every change goes through CI static validation; Unity EditMode remains the game-logic gate.
- Releases are identified by `bundleVersion` + annotated git tag + GitHub release.
- Historical `TASKS/*-breakdown.md` files are archives; they may mention removed files and are not authoritative for v1.1.

## Update (2026-11-13)

The `TASKS/` directory has been removed from the repository. The task queue now lives in GitHub Issues and the PR workflow described in `CONTRIBUTING.md`. The mention of `TASKS/README.md` above describes the state at the time of the decision and is kept for historical accuracy; this ADR is otherwise unchanged.
