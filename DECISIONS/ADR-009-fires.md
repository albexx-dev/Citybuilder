# ADR-009: Пожары — детерминированные возгорания, тушение, разрушение

Date: 2026-11-15. Status: accepted.

## Context

Покрытие пожарных — процент в HUD, ничего не происходит. Нужны видимые пожары: станция решает, отсутствие — риск.

## Decision

- **`FireSystem`** (plain C#, Scripts/Simulation): на каждом тике перебор домов, для домов вне покрытия пожарных — вероятность возгорания через детерминированный хеш `(tick, EntityId)` (FNV-1a, паттерн SupplyCutoff); никаких System.Random.
- **Состояние**: `Dictionary<EntityId, int> burning` (тики горения). Станция в радиусе → тушение за 1 тик. Без станции после `BurnTicks=6` — разрушение дома (клетки освобождаются, жители выселяются через `EvictHome`).
- **Параметры**: `IgniteChancePerTick = 0.002` (≈1 пожар на 8 минут без покрытия), `BurnTicks = 6`.
- **События**: `fire_started`, `fire_extinguished`, `house_burned_down` → `CityEventLog`.
- **Визуал**: `FireOverlayView` (Presentation) — материал пламени по снимку `FireSystem`, НЕ в домене.
- **Сейв**: пожары НЕ сериализуются — после загрузки горящих нет (детерминированный пересчёт).
- **Баланс**: за 30 минут без станций — 0–2 пожара, с полным покрытием — 0.

## Consequences

- Тесты: детерминизм `(tick, EntityId)` → одинаковый результат; тушение; разрушение.
- Лента: события видны, дедуп не задет (сообщения уникальны по дому).
- Предупреждение в ленте: «пожарные 0%» — намёк задолго до первого пожара.
