# ADR-011: Машины-агенты — презентационная симуляция поездок

Date: 2026-11-15. Status: accepted.

## Context

Дороги, маршруты (RouteSystem, задача 056) и пробки (CongestionSystem, 057) считаются в домене, но на улицах ничего не ездит — главный источник «живости» отсутствует. Снимает запрет «транспорт с машинами» из scope lock v1.1.

## Decision

- **Агенты — презентационная симуляция**: домен (население, нужды, экономика) не знает об отдельных машинах. Единственная доменная связь — нагрузка клеток для CongestionSystem (поездка агента = одна «поездка»).
- **Единый `AgentManager`** (plain C#, Scripts/Simulation): пул ≤40 машин, лимиты константами, переиспользование объектов без GC-давления, без Jobs/Burst/async.
- **Расписание**: спавн по игровому часу из `SimulationClock` — утро 7–9 (дом→работа), вечер 17–19 (работа→дом); в остальное время новые агенты не спавнятся, существующие доезжают.
- **Маршруты**: `RouteSystem.FindPath` по дорожным клеткам; нет пути — агент не спавнится (тихий пропуск).
- **Движение**: в Update по реальному времени (не по тикам), 1 клетка ≈ 0.5 с; вид — простой low-poly автомобиль из примитивов (замена на Kenney vehicles — эпик #60); без Rigidbody/физики.
- **Виды**: пул `VehicleAgentView`, переиспользование, скрытие дальних (LOD — эпик #62).
- **Сейв**: агенты не сериализуются (пересчитываются от домов/работ).
- **Качество**: `MaxAgents` — поле для будущих настроек (#69).

## Consequences

- Пробки становятся физическими (#45): машины замедляются на загруженных клетках.
- Тесты: логика менеджера (пул/расписание/маршруты) — чистая, тестируется с fake-провайдером путей.
- Перф: тик ≤5 мс при 40 агентах; без аллокаций в Update.
- Мусоровозы (#52) и пешеходы (#46) переиспользуют AgentManager.
