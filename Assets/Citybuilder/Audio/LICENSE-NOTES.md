# Лицензии аудио-ассетов (EPIC-19)

Все звуковые файлы в папке `Assets/Citybuilder/Audio/` (`click.wav`, `coin.wav`, `pop.wav`, `swoosh.wav`) сгенерированы процедурным математическим синтезом (синусоидальные огибающие 22.05 кГц, 16-бит моно PCM) специально для проекта Citybuilder.

- **Авторство и статус:** оригинальная процедурная генерация в рамках репозитория.
- **Лицензия:** CC0 1.0 Universal (Public Domain Dedication) — свободно для любого использования без ограничений.
- **Сторонние пакеты:** не используются (только встроенный `UnityEngine.AudioSource` / `AudioListener`).
